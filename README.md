# 模玩预定簿

一个本地优先的网页小工具，用来记录模玩预定、愿望单、全款、定金、补款和发售月份。

## 功能

- 新增、编辑、删除预定记录，发售时间精确到月份
- 一键补款，直接记录全部剩余待付款，并支持撤销
- 独立愿望单，可记录目标价格、发售月份、优先级和购买状态
- 每个预定或愿望可添加一张商品图片，支持相册和拍照，自动压缩
- 自动计算补款应付、剩余待付、已支付合计和付款进度
- 发售月份临近时给出提示
- 搜索、筛选和智能排序
- 支持导出 JSON 完整备份（包含愿望单和图片）和 CSV
- 可安装为 PWA，支持离线打开
- 针对 iPhone / iPad 做了移动端适配

## 部署

这是纯静态网页，不需要后端。把本目录部署到任意静态托管即可，例如 GitHub Pages、Netlify、Vercel 或 Cloudflare Pages。

## iPhone / iPad

1. 用 Safari 打开部署后的网址。
2. 点分享按钮，选择“添加到主屏幕”。
3. 从主屏幕图标进入，数据和离线缓存都会保留在这个入口中。

## 数据说明

记录默认保存在当前浏览器的 localStorage 中，商品图片保存在 IndexedDB 中，不会自动同步到其他设备。换设备前使用“导出完整备份”，在新设备上使用“导入备份”。

如果需要 iPhone 和 iPad 实时同步，需要再接一个云端数据库或登录同步服务。
